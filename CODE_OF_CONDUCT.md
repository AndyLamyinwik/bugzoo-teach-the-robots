# Community Code of Conduct / 社群行為準則

BugZoo welcomes people of different backgrounds, identities, languages, and experience levels. Our discussions should make it easier to build thoughtful educational software together.

BugZoo 歡迎不同背景、身分、語言與經驗的參與者。我們希望每個人都能安心討論、學習與協作。

## Expected behavior / 合宜行為

- Be respectful, patient, and specific. Discuss ideas and code without attacking people.
- Accept constructive feedback and acknowledge mistakes. Make room for new contributors and different educational perspectives.
- Protect privacy. Do not share someone else's personal information, private learning records, or confidential messages without permission.
- Avoid harassment, discrimination, threats, sexualized remarks, personal insults, and repeated unwanted contact. Do not use project spaces to intimidate or exclude others.

請尊重他人、耐心溝通，針對想法及程式碼提出具體意見；接受善意回饋並保護個人隱私。騷擾、歧視、威脅、性暗示、人身攻擊、持續的不受歡迎聯絡及公開私人資料均不可接受。

## Scope and response / 適用範圍與處理

This policy applies to repository issues, pull requests, discussions, and other spaces managed for BugZoo, including conduct while representing the project. Maintainers may edit or remove harmful content, ask someone to change their behavior, restrict participation, or block an account. Responses should consider severity, repetition, and the safety of affected people; enforcement is not a public popularity vote.

本準則適用於專案管理的 Issue、PR、討論區及代表專案的活動。維護者可移除有害內容、要求改善、限制參與或封鎖帳號，並依嚴重程度、重複情況及受影響者的安全決定處理方式。

## Reporting / 回報方式

Use GitHub's **Report content** action for harassment or content that violates platform rules. For project moderation, contact a maintainer through a private GitHub contact method they have explicitly published, if available. If none is available, open an issue requesting a private moderation contact, without names, private messages, or sensitive details. Do not post an allegation publicly to establish contact. Security vulnerabilities use the separate [security policy](SECURITY.md).

對騷擾或違反平台規則的內容，可使用 GitHub 的 **Report content**。專案管理問題請使用維護者明確公布的私人 GitHub 聯絡管道；若尚未提供，只建立不含姓名、私人訊息或敏感細節的聯絡請求 Issue。不要為了取得聯絡方式而公開指控。安全漏洞另依安全政策處理。

Maintainers should share report details only as necessary to investigate and respond. This document does not promise absolute confidentiality or a guaranteed response time.

維護者應只在調查及處理所需範圍內分享回報內容。本文件不承諾絕對保密或固定回覆時限。
