# BugZoo 分階段開發計畫

此文件描述候選開發順序，不構成執行後續階段的授權。每次只完成使用者明確指定的階段；階段交付須以實際檔案與驗證結果為依據。

## 第一階段：專案基礎與架構（已建立）

已建立的基礎：

- 檢查現有倉庫，保留已有內容與設定。
- 建立 React、TypeScript Strict Mode、Vite、Tailwind CSS、Vitest、ESLint、Prettier 基礎。
- 製作繁體中文響應式首頁，介紹品牌、玩法與四個規劃中的機器人。
- 建立必要領域契約與精確有理數基礎工具；不實作完整規則引擎。
- 建立 README、AGENTS、架構、路線圖及忽略規則。
- 實際驗證安裝、開發伺服器、型別、lint、測試、格式與正式建置。

此階段的完成界線為可啟動首頁、工程檢查通過、架構邊界與後續工作有明確文件。歷史實測結果見 README；當時沒有機器人遊戲、學習進度、完整雙語切換或部署。

## 第二階段：FractionFox 的完整教學流程（已完成）

本階段以 FractionFox 驗證精確有理數、可解釋迷思與反例教學流程；完成本階段後停止，等待後續指令。

- 實作三個候選規則：正確通分、分子分母各自相加、分子相加且保留第一個分母。
- 保留題目的原始分數寫法，以精確 `bigint` 有理數計算與核對答案。
- 完成外部輸入驗證、正確答案計算、證據核對與候選假設淘汰。
- 建立觀察、猜想、實驗、教學、驗證的五步活動，通過條件後進入成果頁。
- 明確處理無效輸入、錯誤學生答案、無辨識力示例與規則一致性錯誤。
- 完成條件要求只剩正確規則，且學生與機器人都通過三題未見題；保留重設流程。
- 加入對應純函式與整合測試，驗證確定性、精確數學、步驟守衛與課程完成條件，並實測桌面及手機流程。

完成界線：一個可玩的、有解釋與當次驗證證據的 FractionFox 課程。當時其他三個角色維持介紹狀態；不因單一課程而擴大成大型通用引擎。工程驗證結果以 README 的第二階段記錄為準。

2026-10-13 已完成第二階段當次工程驗證及桌面、手機完整通關實測。第二階段交付時停止；後續階段仍由使用者另行授權。

## 第三階段：DiscountPanda 與共用教學引擎（已完成）

只加入 DiscountPanda 的完整五步遊戲：整數分／基點、最終 half-up 捨入、三條真實規則、價格變化圖、有效證據淘汰、三題未見驗證與重設。保留 FractionFox 原有規則、原始分數表示及通關條件。

只有新課程提出實際共同需求時才抽取共用實作；候選規則、驗證、證據與完成條件的模組邊界可以沿用，不預建大型外掛系統。

共用流程實際供兩個機器人使用，數學解析、規則、題庫與專屬視覺維持獨立。完成界線為兩個遊戲都能完整通關，原有 44 個測試保留並通過，新增金額與整合測試通過，桌面與 320px 手機完成實測。MinusMole、ChanceCrow 不在本次範圍。實測結果記錄於 README。

2026-10-13 已完成 110 個測試、工程檢查，以及兩個遊戲在桌面與 320px 手機的完整通關實測。本階段停止，第四階段仍需另行指令。

## 第四階段：MinusMole 與互動式數線（已完成）

使用已驗證的共用流程，加入 MinusMole 的三條整數減法規則、嚴格整數輸入、有效證據排除、三種負數情境未見題與完整五步遊戲。數線由實際計算產生方向、距離、箭頭與起終點，提供動畫重播／跳過及減少動態效果支援；錯誤路徑與正確減法清楚分開。

完成界線：原有 110 個測試保留並通過，新增數學、數線與整合測試通過；首頁三個課程可獨立完成。桌面與 320px 手機完成數線、錯誤輸入、無區分示例、驗證重試、重設與鍵盤驗收。ChanceCrow 不在本階段範圍。實測記錄見 README。

2026-10-13 已完成 172 個測試、全套工程檢查，以及三個遊戲在 1280px 桌面與 320px 手機的完整通關實測。數線重播、略過、負結果鏡射、錯誤答案、無區分示例及重設均經瀏覽器操作確認。減少動態效果有靜態呈現測試，未切換系統偏好。第四階段完成後停止，下一階段須另行授權。

## 第五階段：ChanceCrow 與互動式機率實驗室（已完成）

沿用共用引擎完成第四個課程：兩色球袋、三條精確有理數規則、條件／聯合機率、實體球有序樣本空間及真正不放回抽球。隨機性限於實體模擬，理論計算及證據排除保持確定性。完成五步教學、異色／同色／零事件三種未見題、驗證與重設，保留前三個課程。

完成界線：原有 172 個測試保留並通過，新機率、抽樣、實驗室及整合測試通過；四個機器人可由首頁獨立通關。在 1280px 桌面及 320px 手機驗收抽球、球數變化、樣本空間、錯誤與無區分示例、鍵盤、重設及 Console。

2026-10-13 已完成 257 個測試（保留 172 個、新增 85 個）、全套工程檢查，以及四個遊戲在 1280px 桌面與 320px 手機的完整通關實測。不放回抽球、實體球數、樣本空間、條件／聯合機率、錯誤與無區分示例、驗證重試、重播、重設、鍵盤與 Console 均經實際操作確認。第五階段完成後停止，不自動開始第六階段；詳細當次實測結果及限制見 README。

## 第六階段：本地進度、雙語與學習護照（已完成）

本階段由使用者明確授權。四個課程獨立保存版本、有效實驗、教學證據及已接受的驗證答案；精確整數以字串序列化，讀取時嚴格驗證並重播既有領域命令，重建假設及通關結果。儲存失敗保留可用的記憶體遊戲，損壞與不相容版本只影響各自課程。

全站提供即時繁體中文／英文切換及獨立語言偏好。共用導覽連接首頁、四個課程、Dashboard 與 Learning Passport；總覽與 SVG 成就只來自真實紀錄。Markdown 在瀏覽器本地依目前語言匯出，清除單一／全部進度須確認，保留語言偏好。

2026-10-13 已完成 348 個測試（保留 257 個、新增 91 個）與全套工程檢查。四課程完成與恢復、即時雙語切換、真實統計、雙語 Markdown 下載、確認後單一／全部清除及語言隔離均經實際瀏覽器操作；最終桌面 1280px 與手機 320px 無水平溢出，Console 無 error 或 warning。實測是刷新及關閉／重開分頁，未重啟整個瀏覽器程序或跨瀏覽器。詳細當次記錄與保存上限見 README。沒有登入、雲端同步、第五個機器人、PDF、後端或部署；第六階段完成後立即停止。

## 第七階段：產品品質驗收與發布前優化（已完成）

新增最小 Playwright 開發依賴及 Vite 自動啟動設定。16 個高價值案例分別在桌面與 320px context 執行，涵蓋四個遊戲真實通關、保存／恢復、損壞與版本隔離、重設、雙語、實際 Markdown 下載、鍵盤、減少動態效果及五種寬度。測試不注入假通關、不依賴特定抽球結果、不使用固定延遲或自動重試，並檢查所有頁面的 Console、例外與外部 HTTP 請求。

修復確認對話框的 Tab 邊界、表單錯誤與欄位關聯、已確認的對比度問題；最大樣本空間保留可讀字體及局部鍵盤捲動。損壞／版本不相容資料的新操作不再覆寫原紀錄，直到使用者確認重設。六個 UI 頁面依 hash 入口延遲載入，核心數學、既有教學規則及三題通關守衛保持原行為。

2026-10-14 完成 355 個 Vitest 測試（全部 348 個保留、新增 7 個）、全套工程檢查與正式建置。最終 32 次 E2E 連續兩輪全數通過，零重試。七個主要頁面在 320、375、768、1280、1440px 無頁面水平溢出；另以正式 preview 驗證桌面、手機及 UI 分割後首次首頁的樣式。正式入口 JS 與 gzip 體積分別降低約 26.5% 與 21.8%，總 JS 約增加 2.0%；沒有測量載入時間或 Lighthouse 分數。詳細命令、環境與歷史結果見 README。

本階段未完成的驗證範圍：Firefox／WebKit、真實手機、螢幕閱讀器人工驗收、完整 WCAG 審核、整個瀏覽器程序重啟、Playwright UI 模式及全新 CI 環境。沒有發現阻礙此次 Chrome 驗收通關的問題；以上未驗證範圍不能推定通過。儲存版本更新時仍需設計具體安全遷移，不建立未使用的通用框架。

工作目錄目前沒有 `.git`；第七階段沒有初始化倉庫、建立遠端、推送、發布或部署，交付後立即停止。
